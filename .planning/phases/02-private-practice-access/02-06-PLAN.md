<threat_model>
ASVS 5 Level 1; security enforcement is active and HIGH findings block execution.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser forms to auth API | User credentials, addresses, and reset tokens enter the server from untrusted controls. |
| Session state to rendered workspace | Private identity/content must not survive failed authorization or session expiry. |
| Public audio example to account UI | Public provisional audio observations remain guest state and cannot imply persisted private data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-08 | Spoofing | Auth forms and continuation targets | high | mitigate | Server-authoritative first-sign-in route, safe return allowlist, CSRF/origin protections, and no browser-stored bearer secrets. |
| T-02-09 | Information disclosure | Workspace and session-expiry UI | high | mitigate | Authenticated no-store reads, clear private DOM on 401, and tests for every private-state transition. |
| T-02-10 | Denial of service | Public example and microphone flow | medium | mitigate | Keep audio path independent of auth requests and verify a live guest attempt during expiry. |
| T-02-SC | Tampering | npm package installation | high | mitigate | Preserve the blocking Better Auth provenance/tarball checkpoint before package installation. |

Residual threats: an authenticated user can still capture or copy content displayed in their own browser, and browser extensions may observe rendered content. Server authorization and no-store reduce server-side exposure but cannot prevent local screen capture; account credentials and private content must remain protected at the endpoint boundary.
</threat_model>
