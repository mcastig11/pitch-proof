## Phase Goal

Original ROADMAP goal: A singer can upload a supported printed PDF, review the recognized single vocal part against the original, correct it, and confirm a trustworthy score version for practice.

Derived framing: **As a** singer, **I want to** upload, review and correct a supported printed PDF, **so that** I can confirm a trustworthy score version for practice.

<objective>
Let singers explicitly save/reopen corrections and track review against the original PDF for each measure.
Purpose: Separate unfinished saved work from confirmation while protecting drafts against stale writes and ripple review drift.
Output: CAS draft/review repository and explicit Save draft/review UI with unsaved warning.
</objective>
